## 二、优化方案（逐条）

> 通用约定：**"改基础版"** = 改 `morning_brief_auto.py` / `close_brief_auto.py` 的 main() 模板段；**"改 AI 版"** = 改两个 cron prompt 的"输出结构"段（下详）。

### 2.1 分组分隔线

- **改哪里**：基础版两脚本的 `lines` 组装段（morning 252-285 行 / close 226-259 行）；AI 版两个 prompt 的格式段。
- **改成什么样**：
  - 统一分隔线：独立成行的 `─────`（5 个全角 U+2500，纯文本安全；备选 `···`）。
  - 位置：标题/时间行之后、每个板块标题之前、免责声明上方。
  - 分隔线前后各留一个空行（阅读节奏清晰）；嫌长可只留分隔线，二选一固定下来。
  - 基础版实现：`SEP = "─────"` 常量，各节之间 `lines.append("") + lines.append(SEP) + lines.append("")`；AI 版在 prompt 里写死规则。
- **示例（改后）**：

```text
📊 早盘简报 · AI分析版
🕗 2026-08-13（周四）09:27（北京时间）

─────

🎯 TL;DR
……
─────

📈 A股（早盘）
……
─────

🥇 黄金（伦敦金 XAUUSD）
……
─────

⚠️ 以上为市场数据与公开信息整理，不构成投资建议；市场有风险，决策需谨慎。
```

### 2.2 涨跌色标（红涨绿跌）

- **改哪里**：基础版两脚本的 emoji 取值处（morning 262/281 行、close 236/255 行）；AI 版 prompt 的行情行规则。
- **改成什么样**：遵循中国习惯红涨绿跌，色点放在行情行行首，**必须与正负号/文字并存**（色弱、单色渲染时仍可读方向）：
  - `chg > 0` → `🔴`；`chg < 0` → `🟢`；`chg == 0` → `⚪`
  - 缺数据 → 保持 `⚠️ 获取失败`，不上色标
  - 覆盖范围：A股三指数、美股三大指数、黄金现价行；消息面/分析文本不上色
- **示例**：

```text
改前：- 📈 上证指数 3957.16（+0.27%）
改后：- 🔴 上证指数 3957.16（+0.27%）

改前：- 📉 道琼斯 53770.27（-0.04%）
改后：- 🟢 道琼斯 53770.27（-0.04%）
```

- **可选变体 B**（若想保留方向箭头双通道）：`🔴📈` / `🟢📉`。推荐方案 A（单色点更简洁）；最终由 Hermes 拍板（见"待确认事项"）。

### 2.3 关键位加粗 / 醒目标注（支撑压力、RSI 状态）

- **改哪里**：基础版两脚本的黄金段（morning 268-271 行 / close 243-246 行）；AI 版 prompt 的黄金节规则。
- **改成什么样**：
  - RSI 状态统一符号 + 文字标签（两版同一套阈值，避免每次不一致）：

    | RSI | 符号 | 标签 |
    |---|---|---|
    | ≥ 70 | ⚠️ | 超买 |
    | 60 – 69.9 | 🟡 | 偏强 |
    | 40 – 59.9 | 🟢 | 中性 |
    | 30 – 39.9 | 🟡 | 偏弱 |
    | < 30 | ⚠️ | 超卖 |

  - 支撑/压力统一格式：`支撑：4400 / 4360；压力：4450 / 4500`（早盘版已是此格式，收盘版"参考位：上方压力…→…"改为同款）。
  - 基础版实现：加一个 `rsi_mark(rsi)` 小函数返回 `(符号, 标签)`，黄金段拆成两行（现价一行、高/低/RSI 一行）。
  - 加粗 `**数字**`：默认**不启用**（微信等终端会把 `**` 当字面量显示；且 LLM 加粗不稳定）。若确认只推飞书再作为可选项，仅用于关键价位数字。
- **示例（改后）**：

```text
🥇 黄金（伦敦金 XAUUSD）
- 🔴 现价 4422.13 美元/盎司（+0.31%）
- 🟡 RSI 68.3 偏强（60-70）｜ 高 4449.83 / 低 4398.43
- 参考位：支撑 4400 / 4360；压力 4450 / 4500
```

### 2.4 TL;DR 精简

- **改哪里**：AI 版两个 prompt 的"1. TL;DR"条目；基础版为可选项（见下）。
- **改成什么样**：
  - 固定标题行 `🎯 TL;DR`，正文 **1-2 行，最多 3 行，总长 ≤ 90 字**。
  - 第 1 行：方向 + 一句核心事实；第 2 行：关键看点 / 最大风险。
  - prompt 里明确写"不要写成一段长句"。
- **示例**：

```text
改前（早盘）：
🔑 TL;DR：三大指数集体高开，创业板/科创领涨，科技成长占优；今日关键看美联储 9 月降息预期能否延续（美财长放鸽）+ 量能是否配合，最大风险是连续上涨后的冲高回落。

改后：
🎯 TL;DR
三大指数高开、创业板/科创领涨，科技成长占优。
看点：降息预期能否延续 + 量能配合度；风险：连涨后冲高回落。
```

- **基础版可选**：加一行数据型摘要（脚本按涨跌家数/方向自动生成，如 `🔑 摘要：A股三大指数齐涨，金价偏强，美股涨跌互现`），用于降级时观感一致。零分析成本，属纯数据统计。

### 2.5 免责声明收尾友好化

- **改哪里**：基础版两脚本末行（morning 285 / close 259）；AI 版两个 prompt 的"结尾"条目。
- **改成什么样**：两版各定一版文案、句式一致，分隔线收尾，**不新增被禁措辞**（输出纪律禁"祝您投资顺利"等）：

  - AI 版（候选）：`⚠️ 以上为市场数据与公开信息整理，不构成投资建议；市场有风险，决策需谨慎。`
  - 基础版（候选）：`⚠️ 自动简报（无 AI 分析）· 数据仅供参考；市场有风险，决策需谨慎。`

  保留基础版"无 AI 分析"标识，让用户一眼分辨是兜底版还是分析版。

### 2.6 格式统一（层级、列表、数字）

- **改哪里**：全部四处（两脚本 + 两 prompt）。
- **改成什么样**（统一规范，两版共用）：
  1. 标题行：`📊 早盘简报 · AI分析版` / `📊 收盘简报 · AI分析版`（统一" · "间隔）；基础版 `📊 早盘简报` / `📊 收盘简报`。
  2. 时间行：AI 版 `🕗 2026-08-13（周四）09:27（北京时间）`（统一 🕗 前缀与日期格式）；基础版 `🕗 2026-08-13 09:27:31（北京时间）`（保留 🕗 前缀，冒号改全角）。
  3. 板块标题：`📈 A股（早盘）` / `📉 A股收盘`（语义保留，格式一致）；`🥇 黄金（伦敦金 XAUUSD）`；`🇺🇸 美股隔夜`。AI 版早盘**强制独立美股节**（今天被并进消息面了）。
  4. 列表符号：一律 `- ` 前缀（基础版从两空格缩进改 `- `）；嵌套子项 `  - `（最多两级）；消息面不再用 `1. 2. 3.`。
  5. 数字格式：价格统一 2 位小数、涨跌幅统一 `+x.xx%` / `-x.xx%`（不加括号）、RSI 1 位小数、缺失 `-`。
  6. 黄金行拆分：现价/涨跌一行；高/低/RSI 一行（基础版同样拆，不再六项塞一行）。
  7. 子标题统一用 `【行情分析】` 风格（收盘版现有），早盘"盘前分析："对齐为 `【盘前分析】`。

- **AI 版落地方式**：prompt 的"输出结构"段改写成"格式规范 + 完整样例输出块（few-shot）"，把上面 1-7 条直接给模型照着输出；同时保留原有的【隐私铁律】与 skill 输出纪律（禁表格、禁自述性内容、禁元叙述）原文，不删减。

## 四、飞书渲染注意

1. **禁 markdown 表格**：飞书 post 消息的 md 标签不支持表格。现有输出纪律已禁，AI prompt 里继续保留"禁表格"，基础版天然无表格。
2. **分隔线**：用全角字符 `─────`（或 `···`），**不要用 markdown 的 `---`**（会被当横向线语法，渲染不稳定）。
3. **列表**：`- ` 前缀在飞书渲染为列表项；嵌套缩进 `  - ` 最多两级；不要用 `#` 标题、`>` 引用、代码块围栏（连续三个反引号）——这些在飞书渲染不可控。
4. **emoji 颜色不保证**：部分客户端/深色主题下 🔴🟢 可能显示为单色 → 色标必须与"正负号 + 箭头/文字"并存（三通道兜底）。
5. **加粗**：飞书 post 支持 `**粗体**`，但微信等不渲染（显示字面星号）→ 默认不用；若确认只推飞书，仅对关键价位数字启用。
6. **排版节奏**：分隔线与空行二选一定节奏，避免每条消息过长；整条推送建议控制在手机两屏内（AI 版约 35-45 行）。

## 五、风险与兼容

### 5.1 指纹去重（fingerprint_guard）

机制：对输出文本逐行排除**以 `🕗` 开头**的行后做 sha256，与 `.morning_brief.fp` / `.close_brief.fp` 比较，相同则静默不推。

对本方案的影响：

1. **静态改动有一次噪音**：模板结构/文案/分隔线/色标都会改变指纹 → 上线后第一次运行即使行情未变也会推一次（一次性），随后指纹稳定、去重恢复。**验收当天会多一条推送，属预期**。
2. **红线：动态行必须带 `🕗` 前缀**。若在基础版里新增"🗓 2026-08-13（周四）"这类日期行且不以 `🕗` 开头 → 指纹每天变化 → **去重彻底失效、每天必推**。处理方式二选一：
   - 时间信息全部合并进现有 `🕗` 行（推荐）；或
   - 同步扩展 `fingerprint_guard` 的排除前缀（`ln.startswith(("🕗", "🗓", "📅"))`）。
3. **数据派生内容无影响**：色标、RSI 状态符号由数据计算而来，指纹随数据变化，去重语义不变（节假日数据未变仍静默）。
4. 改模板前保留一份原脚本副本（可回滚）；`.fp` 文件不用动。

### 5.2 降级链路（分析版失败 → 基础版兜底）

`push_pending_brief.py` 逻辑：pending 文件存在且非空 → 投递并删文件；否则调基础版脚本（含指纹守护）。

- **两处必须同批改、同批验收**：基础版与 AI 版共用同一套视觉规范，否则分析失败降级时用户看到两种风格（P10）。
- **去重差异**：AI 版不走指纹（靠删除 pending 文件防重复）；基础版走指纹 → 基础版改动有 5.1 的一次性噪音，AI 版改动无。
- **数据时点差异**：降级时基础版现场重新抓数，数值与当天早盘 AI 版可能不同（时点不同），不是 bug，验收时别误判。
- 验收用例：① pending 文件正常 → 输出为 AI 版格式；② 删除 pending 文件模拟分析失败 → 输出为基础版格式（应同样有分隔线/色标/免责声明）。

### 5.3 其它

- **跨平台**：飞书为主、微信可加（skill 允许）；🔴🟢 在微信也可能单色 → 正负号兜底。WhatsApp 已退役，不再考虑。
- **隐私铁律**：本方案只动视觉格式，不新增任何持仓/金额/仓位相关内容；免责声明文案里不出现被禁措辞。
- **消息面数字核对**：skill 的"新闻个股数字必须实时核对"铁律不动（2026-08-13 长鑫科技教训）。
- **cron 并发风险**：改 prompt 前备份 `jobs.json`；改后核对 job_id，防止并行会话覆盖（skill 实测教训）。
- **钻仔侧不动**：本方案仅金仔侧；钻仔（OpenClaw，首尔）简报如需同样美化，由用户另行拍板同步。
